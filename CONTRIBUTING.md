# Contributing to SFEXIS

Use [GitHub issues](https://github.com/fedefirefox/SFEXIS/issues) for reproducible
bugs, scientific questions or verified provenance corrections. Include the
release/commit, MATLAB version, installed toolboxes, example/settings, expected
result, actual result and error text. Share only data you have permission to publish.

The primary scripts preserve Federico Vismarra's original calculation structure.
Keep all complete example bodies aligned; put alternative designs and AI/GPT
automation in `ai_companion/`. Never rewrite the `legacy/` archive. Describe
changes to physical conventions explicitly and add an appropriate numerical
control when changing calculations. Follow `AGENTS.md` and run the checks in
[ENVIRONMENT.md](ENVIRONMENT.md).

Keep author credit, the six-author paper citation and third-party notices.
New original contributions to project files should use BSD-3-Clause; identify
any separately licensed material and its source. Contribute only work you have
the right to license. The exclusions in [LICENSING.md](LICENSING.md) still apply;
a pull request cannot resolve someone else's rights by assertion.
